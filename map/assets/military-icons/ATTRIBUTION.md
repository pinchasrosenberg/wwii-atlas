# Military map icons

The PNG icons in this directory use the Icons8 **Color** style and are stored locally so the map remains available offline.

Source searches and icon pages:

- Tank: https://icons8.com/icons/set/tank
- Infantry: https://icons8.com/icons/set/military-soldier
- Artillery: https://icons8.com/icons/set/artillery
- Paratroopers: https://icons8.com/icons/set/parachute
- Vehicle/transport: https://icons8.com/icons/set/military-truck
- Aircraft: https://icons8.com/icons/set/fighter-plane
- Naval: https://icons8.com/icons/set/battleship-game
- Bases and facilities: https://icons8.com/icons/set/military-base
- Supporting pictograms: https://icons8.com/icons

License and attribution: https://icons8.com/license

Free Icons8 PNG use requires a visible link to Icons8. Keep the attribution link in the map information panel and in this file. If the project later obtains a paid Icons8 license, record that license here before removing the visible attribution.

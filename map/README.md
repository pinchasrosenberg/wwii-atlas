# אטלס מלחמת העולם השנייה — שלבים 1–8

מפת זמן אינטראקטיבית בעברית לגבולות המדיניים ולמערכה הימית במלחמת העולם
השנייה. MapLibre ו־Deck.gl מאוחסנים באתר עצמו. תוכן המלחמה נקרא מ־API ציבורי לקריאה בלבד מעל גרף הידע של הפרויקט.

## מה אפשר לעשות

- לגרור את ציר הזמן בין ספטמבר 1939 לספטמבר 1945.
- לגרור את המפה, לעשות זום בגלגלת/צביטה או להשתמש בכפתורי `+` ו־`−`.
- לעבור בין העולם, אירופה, האוקיינוס האטלנטי והאוקיינוס השקט.
- לראות קרבות פעילים באותו תאריך בזירות שונות בעולם.
- להדליק ולכבות גבולות היסטוריים, נתיבי אספקה, אבדות ימיות ו"פער האוויר".
- להציג תוואי קרקע ותבליט מקומי מתחת לגבולות המשתנים לפי ציר הזמן.
- ללחוץ על ישות כדי לראות תאריכים, מקור והאם המידע מקורִי או נגזר.
- לחפש מקום בכל אחד משמותיו ההיסטוריים, למשל למברג / Lviv / Lwów.
- לחשב נתיב אספקה, לסנן לפי מטען ולראות תפוקה לאורך זמן.
- להציג מסילות, מחנות, טרנספורטים, חזיתות, סיוע, רעב ועקורים.
- להפעיל מצב "מדוע" מכרטיס קרב ולהדגיש את שרשרת האספקה הרלוונטית.
- לצאת לסיור מודרך, להשוות תאריכים ולייצא CSV או GeoJSON.
- לשתף כתובת שמשחזרת את התאריך, השכבות והמצלמה.
- לעבור למצב "בחירה וקשרים" ולנווט בשרשרת מפעל–נמל–נתיב–מפקדה–קרב.
- להבחין בכל ישות וקשר בין `real`,‏ `mixed` ו־`mock`; קשרי העיצוב אינם מוצגים כעובדה.

## הרצה

הרצה מקומית:

```bash
python3 -m http.server 8000
```

ואז `http://localhost:8000`.

פתיחת `index.html` בלחיצה כפולה **לא תעבוד** — ES modules חסומים
מ-`file://` בכל הדפדפנים. זו הסיבה היחידה שנדרש שרת.

המפה עצמה עובדת במצב `static-first`: התבליט נטען כאריחים מקומיים לפי האזור
הנראה, ושכבות המלחמה הקיימות נטענות פעם אחת. גרירה וזום אינם מפעילים מחדש
שאילתת מסד. API הקריאה נשאר זמין לחיפוש, כרטיסי ישויות ושכבות עתידיות כבדות.

## נתונים: סטטיים מול הגרף הציבורי

שכבות הבסיס (גבולות CShapes, תבליט Natural Earth, הכרונולוגיות והאבדות
הימיות המובחרות של שלב 2 והנתונים המייצגים של שלבים 3–8) הן קבצים סטטיים
ממקורות פתוחים תחת `data/`.

תוכן המלחמה עצמו — כ־2,500 קרבות, מחנות וגטאות, אבדות ימיות, מפעלים ומטרות
הפצצה — **אינו נשמר באתר**. הוא נקרא בזמן ריצה מה־API הציבורי לקריאה בלבד
(`../api`) שמעל הגרף המתארח, דרך `src/core/data-store.js`. כתובת ה־API
מוגדרת בתגית `<meta name="ww2-graph-api">`, ו־`npm run set-api-url -- <url>`
מעדכן אותה יחד עם ה־CSP. אם ה־API אינו זמין, המפה עולה כרגיל והשכבות האלה
נשארות ריקות.

## בדיקה ובנייה

```bash
npm test
npm run build
```

הבנייה יוצרת אתר סטטי תחת `dist/` (GitHub Pages). כל הבדיקות רצות ללא שירות רשת.

## שלושת המסלולים בקוד

| נתיב | מסלול | מכיר את מלחמת העולם השנייה? |
|---|---|---|
| `src/core/` | **A — שלד** | לא. אף מחרוזת. |
| `src/config.js` | הגבול | כן — זה הקובץ היחיד בצד הלקוח שכן |
| `src/layers/` | **B + C** | כן |
| `src/ui/` | **A — שלד** | לא, חוץ מפורמט התאריך |

המבחן: החלף את `config.js` ואת `layers/` — ותקבל אטלס אחר לגמרי על
אותו מנוע. אם מצאת את עצמך מייבא מ-`layers/` לתוך `core/`, שברת את ההפרדה.

## מה נבנה כאן

| רכיב | קובץ | מה הוא פותר |
|---|---|---|
| מנוע זמן | `core/time-engine.js` | זמן כמספר שלם (ימים מאפוק), לא Date — כדי שיעבור ל-shader |
| רזולוציה דינמית | `core/time-engine.js` + `config.js` | תשעה חלונות מבצע שבהם הצעד עולה לשבועי/יומי (סעיף 5.2) |
| רג'יסטר שכבות | `core/layer-registry.js` | טעינה עצלה, נראות, שקיפות, מקרא דינמי — בלי לדעת מה השכבות |
| דרגי ביצועים | `core/perf-tier.js` | זיהוי GPU אמיתי, ניטור FPS, ירידת דרג, התאוששות מ-context loss |
| כרטיס ישות | `core/entity-card.js` | `textContent` בלבד, `rel="noopener"`, תג הסקה, אזהרה על ישות ללא מקור |
| קישור עומק | `core/deep-link.js` | URL שמשחזר תאריך + שכבות + מצלמה |
| סרגל זמן | `ui/timeline.js` | היסטוגרמת פעילות + סימון חלונות + ניווט מקלדת |

## סייג מחקרי

המערכת המלאה עובדת, אך הקורפוס אינו מתיימר להיות מלא. הגבולות הקיימים הם
גבולות מדינה לפי CShapes; קווי חזית, מסילות וטרנספורטים מסומנים כשחזור
כאשר אין מערך פתוח מאומת. נתוני ים ומחנות נשמרו בכוונה כתת־קבוצה שניתן
להפיץ, ולא כהעתקה ממאגרים שמגבילים שימוש.

## איחוד שתי המפות — יומן שינוי

‏על המחשב היו שתי מפות: ‏`ww2_timeline_map.html` (‏Leaflet, קובץ אחד)
‏והאטלס הזה. הישנה נראתה טוב יותר, וההשוואה חשפה **למה**.

⚠️ **קנבס מפת הבסיס נשאר 250×187 בזמן שהחלון 800×450.**
‏‏MapLibre קובע את גודל הקנבס לפי המכל ברגע היצירה — והוא נוצר בזמן
שמסך הטעינה עוד פרוס. מפת הבסיס צוירה בפינה, וכל השאר היה `background`
‏של ‏CSS בצבע אוקיינוס. **זו הייתה הסיבה האמיתית לכך שהמפה נראתה כמו
כתם צבע בלי קרקע.** נוסף `ResizeObserver`, והרקע הוחלף לנייר: פער
נקרא כנייר ריק ולא כים.

⚠️ **‏deck.gl אינו מצייר עברית ב-`TextLayer`.**
‏שמות המדינות נבנו — 27 פריטים הגיעו לשכבה — ועל המסך לא הופיע שם
אחד. זו מפה עברית שכל תוויות המפה שלה היו בלתי נראות. התוויות עברו
ל-`ui/label-canvas.js`, קנבס דו-ממדי עם `fillText`, בדיוק כמו במפה
האחרת. מגיע איתו גם הילה אמיתית וקו מוביל מהנקודה אל השם.
‏(‏`characterSet` חסר היה בעיה נוספת ואמיתית בשש שכבות טקסט, ותוקן —
אבל הוא לבדו לא הספיק לעברית.)

⚠️ **סף שטח קבוע במקום פריסה.** שמות המדינות סוננו לפי `area ≥ 80`,
ובתקופה טיפוסית רק מדינה אחת עוברת — מפה של אירופה עם שם אחד. שמות
הערים היו כבויים מתחת לזום 5.5. עכשיו `layers/map-labels.js` מנסה
את כולן לפי חשיבות ומוותר רק כשאין מקום, כמו אטלס נייר.

⚠️ **דמות ורקע.** מילוי השטחים היה באטימות ~73% ועוד `opacity: .92`,
כלומר הבסיס לא נראה בכלל. שטיפה חלשה עם קו גבול חזק נותנת את שתי
הקריאות. **שטח כבוש קיבל גוון נפרד** — צרפת ביוני 1941 באותו אדום
כמו גרמניה היא טענה, לא עובדה.

⚠️ **סימן שאינו ברור אינו מוצג.** רדיוס נקודת העיר נגזר מ-`jpop`,
גודל הקהילה היהודית: קורא שרואה עיגול גדול מבין ״עיר גדולה״, וזה לא
מה שהמספר אומר. הנקודה אחידה עכשיו; הצבע נושא את מה שידוע (נפלה ·
שוחררה · אחר), והמקרא אומר במפורש מהו סדר הדירוג.

⚠️ **מקור אריחים מרוחק — נוסה ונדחה.** שכבת תבליט עולמית נחסמה בסביבת
ההרצה והמפה נתקעה על מסך הטעינה: תלות מרוחקת הפכה מפה שעבדה למפה
שלא נפתחת. יש בדיקה שנכשלת אם מישהו יחזיר מקור כזה.
